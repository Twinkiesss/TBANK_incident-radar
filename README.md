# Incident Radar

CLI-утилита для анализа NGINX access-логов. Программа читает один или несколько
источников, разбирает строки, фильтрует записи по датам и формирует отчёт
в JSON или Markdown.

## Требования

- JDK 25 или новее;
- Gradle Wrapper уже находится в проекте, отдельно устанавливать Gradle не нужно.

Проверить Java:

```powershell
java -version
